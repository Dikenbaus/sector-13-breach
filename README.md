# Sector 13: Breach

Оригинальный мобильный браузерный ретро-FPS с двумя режимами: Deathmatch и кооператив против монстров.

## Что уже работает

- псевдо-3D raycasting без тяжёлых клиентских зависимостей;
- управление с клавиатуры/мыши и двумя сенсорными стиками;
- офлайн-тренировка против монстров;
- сетевые комнаты на 2–4 игроков по короткому коду;
- Deathmatch и кооператив;
- здоровье, стрельба, очки, смерть и возрождение;
- PWA-манифест и адаптивный мобильный интерфейс;
- WebSocket-сервер только на встроенных модулях Node.js.

## Локальный запуск

В одном терминале:

```bash
cd server
npm start
```

Во втором терминале:

```bash
cd client
python3 -m http.server 8080
```

Откройте `http://localhost:8080`, в поле сервера укажите `ws://localhost:3000`.

## Публикация

### Render — сервер

Репозиторий содержит `render.yaml`. Создайте Blueprint в Render из этого репозитория либо Web Service со значениями:

- Root Directory: `server`
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check: `/health`

### Vercel — клиент

Импортируйте репозиторий как отдельный проект:

- Root Directory: `client`
- Framework Preset: `Other`
- Build Command: оставить пустым
- Output Directory: `.`

После публикации введите выданный Render адрес, заменив `https://` на `wss://`. Браузер сохранит адрес локально.

## Управление

- Компьютер: `WASD`, стрелки или мышь, `Пробел` — огонь.
- Телефон: левый стик — движение, правый — обзор, красная кнопка — огонь.

## Ограничения MVP

Это ранняя игровая версия. Сервер ограничивает комнату четырьмя игроками, но пока использует упрощённую валидацию перемещения и попаданий. Перед соревновательным публичным запуском нужны серверная проверка стен, интерполяция, защита от читов и нагрузочное тестирование.
